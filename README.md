# トリッカル装備設計図・最小周回計算ツール

必要な装備設計図と個数から、総周回数が最小になるステージの組み合わせを計算する、個人利用向けスマートフォンWebアプリです。

## 現在の状態

MVPを実装済みです。初期データには、参照Wikiの表を正規化した56種類の設計図と280ステージを収録しています。

主な機能:

- 欲しい設計図と必要数から、総周回数が最小になるステージ構成を計算
- ランク・分類の複数絞り込みと、設計図の一括選択
- 必要数を変更するたびに結果を自動更新
- 同時ドロップと副産物を考慮した厳密解の探索
- 設計図・アイコン・ステージ・ドロップ表の端末内編集
- 設計図とステージの名称・表示順を属性から自動生成
- IndexedDBへのマスターデータ保存
- JSONバックアップの書き出しと復元
- PWAとしてのインストールと、一度読み込んだ後のオフライン利用

## ローカルでの確認

Node.js 20以降を用意し、リポジトリのルートで次を実行します。

```shell
npm test
npm run build
npm run serve
```

`http://127.0.0.1:4173/`を開くと、`dist`へ生成された本番用サイトを確認できます。

## GitHub Pages

`main`ブランチへ反映すると、GitHub Actionsがテストとビルドを行い、GitHub Pagesへ配置します。リポジトリの可視性とGitHubプランによっては、先にPagesを利用できる状態へ変更する必要があります。

GitHubのリポジトリ画面では、`Settings` → `Pages` → `Build and deployment` の`Source`を`GitHub Actions`にします。

## データについて

初期データは2026年8月4日に参照Wikiから読み取った内容を基にしています。Wikiの更新は自動反映されません。新しい設計図やステージは、アプリの「データ編集」から追加できます。
