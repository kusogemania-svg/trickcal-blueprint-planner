# Blueprint icon sources

The 56 WebP files in this directory were retrieved from the blueprint images published on the following page on 2026-08-04:

https://wikiwiki.jp/thetrickal/%E8%A3%85%E5%82%99%E8%A8%AD%E8%A8%88%E5%9B%B3

Each filename is the corresponding two-digit blueprint code (`rank` followed by `category code`). The images are used as the bundled default icons for this personal tool. Rights to the original game images remain with their respective rights holders.
